MINI FORT BR — SERVEUR EN LIGNE
1) Mets ces fichiers (server.js, package.json, index.html) dans un dépôt GitHub.
2) Sur render.com : New > Web Service > ton dépôt. Build: npm install — Start: npm start. (Gratuit.)
3) Ouvre l'adresse donnée par Render (https://xxx.onrender.com) : le jeu se charge et l'adresse du serveur est pré-remplie.
4) Chaque ami ouvre la même adresse, tape le même nom de salle, puis « JOUER EN LIGNE ».
Test local : npm install && npm start, puis http://localhost:8080
